# Архитектура звукового движка (Audio Engine Architecture)

## 1. Назначение и контекст

Модуль `AmbientAudioEngine` (`src/core/audio/`) предназначен для создания персонализированных звуковых ландшафтов (Ambient Soundscapes), способствующих глубокой концентрации, релаксации и продуктивной работе пользователя в новой вкладке DashFlow.

Движок полностью автономен и не требует загрузки аудиофайлов из сети — все звуки (шум дождя, потрескивание костра, океанский прибой, шелест ветра в лесу, фоновый гул кафе, белый шум, колокол Помодоро) синтезируются **процедурно** в реальном времени с помощью Web Audio API.

---

## 2. Структура компонентов

```
src/core/audio/
├── audioContext.ts       # Управление жизненным циклом AudioContext (ленивая инициализация, safe resume)
├── soundSynthesizers.ts  # Процедурные синтезаторы 6 звуковых дорожек и колокола Помодоро
├── audioStore.ts         # Zustand-стор с персистентностью в localStorage
└── index.ts              # Публичный интерфейс модуля
```

---

## 3. Процедурные синтезаторы

Каждый синтезатор возвращает объект интерфейса `SoundInstance`:
```typescript
export interface SoundInstance {
  setVolume: (volume: number) => void;
  stop: () => void;
}
```

1. **Дождь (Rain):** Генерация непрерывного розового шума (алгоритм Voss-McCartney) с низкочастотной фильтрацией (`lowpass 1200Hz`).
2. **Костёр (Campfire):** Низкочастотный розовый шум пламени (`lowpass 400Hz`) с органической модуляцией.
3. **Океанские волны (Ocean Waves):** Низкочастотный генератор (LFO 0.15Hz), модулирующий срез полосового фильтра для создания периодического шума накатывающих волн.
4. **Лес и ветер (Forest):** Полосовой фильтр (`bandpass 800Hz, Q: 1.2`) с резонансным дыханием ветра.
5. **Кафе (Coffee Shop):** Теплый низкочастотный гул (`lowpass 900Hz`) с эффектом многоголосия.
6. **Шум концентрации (White/Pink Noise):** Высокочастотный белый/розовый шум (`lowpass 3000Hz`) для маскировки внешних отвлекающих звуков.
7. **Колокол Помодоро (Pomodoro Bell):** Чистый синусоидальный тон (`880Hz` $\to$ `440Hz`) с экспоненциальным затуханием амплитуды за 1.5 секунды.

---

## 4. Управление состоянием (`useAudioStore`)

- **Мультитрековость:** Пользователь может одновременно включать несколько звуковых дорожек и настраивать их баланс громкости.
- **Мастер-громкость и Mute:** Централизованное управление общим уровнем звука и мгновенное выключение.
- **Персистентность:** Уровни громкости и настройки сохраняются в `localStorage` под ключом `dashflow_ambient_audio_v1`.
- **Энергоэффективность:** При отключении дорожек ноды Web Audio API немедленно останавливаются и отключаются от графа (`disconnect()`), предотвращая нагрузку на CPU.

---

## 5. Безопасность и политики браузера

В соответствии с Autoplay Policy современных браузеров (Chrome/Brave/Edge), `AudioContext` инициализируется в состоянии `suspended` и автоматически возобновляется (`resume()`) при первом пользовательском взаимодействии (клик по переключателю дорожки).
