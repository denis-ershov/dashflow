# Архитектура напоминаний

## Хранилище и поток данных

- Item с `remindAt` остаётся в IndexedDB. Завершённые, архивные и удалённые записи исключаются из расписания. Миграции схемы и формата экспорта не требуются.
- Интерфейс предлагает доступ к системным уведомлениям при первом сохранении напоминания. При отказе срок всё равно сохраняется. Наступившие напоминания видны во «Входящих» и в отдельном окне, а число на иконке расширения показывает количество активных напоминаний.
- После фиксации изменений `events.ts` синхронизирует открытые вкладки через `BroadcastChannel` и пробуждает браузерный фон через `runtime.sendMessage`. Фон принимает запрос только от своего расширения и перечитывает локальную базу.
- `scheduler.ts` объединяет повторные запросы и назначает один будильник на ближайший будущий срок. При запуске браузера, обновлении и срабатывании будильника расписание восстанавливается из Item.

## Доставка и действия

- В `chrome.storage.local` хранится журнал ключей текущих попыток доставки. Ключ состоит из id записи и момента напоминания. Такой ключ записывается перед показом уведомления. Если браузер завершит фон между записью и показом, напоминание сохранится в списке и на бейдже.
- Chrome предлагает действия «Готово» и «Через час». Они сверяют срок и версию Item, чтобы старое уведомление не меняло актуальные данные. В Firefox нажатие на уведомление открывает страницу записи с теми же действиями. [Chrome Alarms](https://developer.chrome.com/docs/extensions/reference/api/alarms), [Firefox notifications](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/notifications/onButtonClicked).
- Разрешение `alarms` обязательно. Разрешение `notifications` запрашивается по действию пользователя. Заголовок Item передаётся локальному механизму уведомлений браузера. Расписание и журнал не отправляются по сети.

## Проверки

Юнит-тесты покрывают восстановление, повторную доставку, устаревший срок и отказ в разрешении. Chromium E2E закрывает вкладку до срока, проверяет бейдж и откладывает наступившее напоминание из резервного окна. Для нативного отображения и клика в Firefox нужна проверка с системным центром уведомлений.
