# Архитектура интернационализации (i18n Architecture)

## 1. Введение и назначение

Модуль `@/core/i18n` обеспечивает полную поддержку мультиязычности DashFlow (русский `ru` и английский `en`), форматирование дат, чисел и плюрализацию на базе стандартов `Intl`.

---

## 2. Структура модуля

```
src/core/i18n/
├── types.ts           # Типы языков (SupportedLanguage), параметры интерполяции, вывод ключей
├── locales/
│   ├── ru.ts          # Русский словарь (канонический источник)
│   └── en.ts          # Английский словарь (100% покрытие ключей ru)
├── i18n.ts            # Чистые функции перевода t(), интерполяции, плюрализации и форматирования
├── i18nStore.ts       # Zustand-стор языка с автосохранением в хранилище
├── useTranslation.ts  # Реактивный React-хук useTranslation
└── index.ts           # Единый реэкспорт
```

---

## 3. Ключевые принципы и гарантии

1. **Строгая типизация `TranslationKey`**:
   Тип `TranslationKey` автоматически выводится рекурсивно из структуры объекта русского словаря `typeof ru`. Любая опечатка в ключе локализации приводит к ошибке компиляции TypeScript.
2. **Гарантия совпадения словарей (Правило 94)**:
   Unit-тест `tests/unit/core/i18n.test.ts` выполняет рекурсивное сравнение ключей `ru.ts` и `en.ts`, предотвращая появление непереведенных или устаревших фрагментов.
3. **Безопасный fallback (Правило 43.12)**:
   Пользователю никогда не выводятся сырые пути ключей (вроде `widgets.clock`). Если ключ не найден в текущей локали, берется значение из русского словаря. Если ключ отсутствует везде, возвращается безопасный дефис `—`.
4. **Стандартная плюрализация и форматирование**:
   Используются нативные браузерные API `Intl.PluralRules`, `Intl.DateTimeFormat` и `Intl.NumberFormat`, исключающие внешние тяжелые зависимости.
