# План реализации: Этап 6. Финальная полировка, Root ErrorBoundary, E2E/интеграционные тесты и синхронизация документации

## 1. Цели и задачи этапа

1. **Корневой предохранитель ошибок (`RootErrorBoundary`):**
   - Добавить глобальный компонент `RootErrorBoundary` для `App.tsx` с изоляцией от утечек приватных данных в логи (Спецификация Секция 6, Правила 18, 32).
   - Предоставить безопасный UX восстановления (кнопка «Перезагрузить страницу» и «Сбросить макет на стандартный»).

2. **Доступность и интерактивность (A11y & Motion):**
   - Проверить поддержку `prefers-reduced-motion` в глобальных анимациях и Tailwind.
   - Проверить фокус-ловушки (focus trap) и навигацию по `Escape` во всех модальных окнах (`Modal.tsx`, `Drawer.tsx`).

3. **Интеграционные и E2E-тесты полного сценария:**
   - Написать сквозной тест жизненного цикла пользователя: старт $\to$ смена темы/обоев $\to$ установка виджетов $\to$ добавление декларативного плагина $\to$ проверка валидаций.
   - Обеспечить полное покрытие всех критических сценариев.

4. **Полная синхронизация архитектурной документации (`docs/`):**
   - Обновить `docs/PLUGIN_SDK_ARCHITECTURE.md` (декларативные манифесты, песочница).
   - Обновить `docs/THEME_ENGINE_ARCHITECTURE.md` (3-уровневые токены, цветовая математика).
   - Обновить `docs/LAYOUT_ENGINE_ARCHITECTURE.md` (адаптивная сетка, NavRail).
   - Обновить `docs/SECURITY_ARCHITECTURE.md` (CSP, host permissions, изоляция storage).
   - Обновить `docs/WIDGET_ENGINE_ARCHITECTURE.md` (ленивый реестр, манифесты).
   - Обновить `docs/CORE_ARCHITECTURE.md` (структура слоев core).
   - Исправить `docs/technical specifications.md` (точка входа `src/entrypoints/`).
   - Добавить финальный релиз `[2.0.0]` в `docs/CHANGELOG.md`.

5. **Финальный аудит качества и сборка:**
   - Прогон `npm test`, `npx tsc --noEmit`, `npm run lint`, `npm run build`.
   - Проверка размера бандла и соответствия MV3.
