# План реализации: Этап 3 — Движок обоев 2.0 и Ambient Soundscapes (Web Audio API)

## Цель этапа

Создать атмосферный движок звуковых ландшафтов (дождь, костёр, волны океана, лес, кафе, белый шум) на базе чистого процедурного Web Audio API и усовершенствовать движок обоев с живым размытием (`blur`) и затемнением (`scrim`) в соответствии с ТЗ §5.6 и стандартами Reflect New Tab.

---

## Задачи этапа

### 1. Процедурный звуковой движок `AmbientAudioEngine` (`src/core/audio/`)
- [ ] **`audioContext.ts`**:
  - Инициализация и безопасное возобновление `AudioContext` по взаимодействию пользователя (политика автовоспроизведения браузера).
- [ ] **`soundSynthesizers.ts`**:
  - Синтезатор дождя (фильтрованный розовый шум + всплески капель);
  - Синтезатор костра (низкочастотный гул пламени + случайные щелчки искр);
  - Синтезатор волн океана (LFO модуляция прилива и отлива);
  - Синтезатор леса и ветра (гармонические шумы ветра);
  - Синтезатор кафе (теплый низкочастотный фоновый гул);
  - Синтезатор белого и розового шума для глубокого фокуса;
  - Синтезатор колокола / гонга для таймера Помодоро.
- [ ] **`audioStore.ts`**:
  - Zustand-стор управления звуками: активные звуковые дорожки, индивидуальная громкость, мастер-громкость, сохранение настроек.

### 2. Пользовательский интерфейс звуков (`src/features/audio/`)
- [ ] **`AmbientSoundDrawer.tsx`**:
  - Стеклянная выдвижная панель со списком 6 звуковых ландшафтов.
  - Индивидуальные тумблеры и ползунки громкости (`Slider`).
  - Мастер-контроль (кнопка воспроизведения/паузы всех звуков, общая громкость).
- [ ] Интеграция кнопки звуков в `FloatingDock.tsx`.

### 3. Движок обоев `WallpaperEngine` 2.0 (`src/features/appearance/`)
- [ ] **Каталог HD-обоев:**
  - Предустановленные темы обоев (Природа, Архитектура, Градиенты, Космос, Минимализм).
- [ ] **Живые регуляторы размытия и затемнения:**
  - Ползунок **Размытие (0–20 px)** $\to$ `--app-blur`;
  - Ползунок **Затемнение (0–80%)** $\to$ `--app-scrim`.
- [ ] **Загрузка пользовательских обоев:**
  - Сохранение base64/Blob в `IndexedDB` с мгновенным применением.

### 4. Тестирование и проверка качества
- [ ] Unit-тесты для аудио-синтезаторов и `audioStore`.
- [ ] Component-тесты для `AmbientSoundDrawer` и `WallpaperPicker`.
- [ ] Проверка `npx tsc --noEmit`, `npm run lint`, `npm test`, `npm run build`.
- [ ] Обновление `docs/CHANGELOG.md` и архитектурной документации.

---

## Критерии приёмки
1. Все 6 звуковых дорожек синтезируются процедурно через Web Audio API без использования внешних файлов и без сетевых задержек.
2. Ползунки размытия и затемнения мгновенно меняют визуальный вид обоев.
3. 100% тестов пройдены, 0 ошибок TypeScript и ESLint.
