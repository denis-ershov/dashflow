# План реализации: Этап 1 — Дизайн-система нового поколения (Glass & Typography)

## Цель этапа

Создать визуальный и компонентный фундамент DashFlow 3.0: подключить премиальные шрифты, внедрить многослойные токены нео-стекла (Glassmorphism), обновить палитры и реализовать полный набор доступных UI primitives в соответствии с ТЗ §1.4 и стандартами Linear/Apple/Reflect.

---

## Задачи этапа

### 1. Подключение шрифтов и типографики
- [ ] В `src/entrypoints/newtab/index.html` подключить Google Fonts (предзагрузка через `preconnect`):
  - **Sofia Sans** (основной шрифт по ТЗ §1.2);
  - **Inter** (чистый технический гротеск);
  - **Nunito** (мягкий дружелюбный sans);
  - **Roboto Slab** (элегантная антиква);
  - **JetBrains Mono** (моноширинный шрифт);
  - **Outfit** (геометричный дисплейный гротеск).
- [ ] В `src/styles/tokens.css` и `src/styles/globals.css` определить переменные шрифтов:
  - `--font-sans`, `--font-display`, `--font-serif`, `--font-mono`, `--font-sofia`.

### 2. Токены нео-стекла и темы (Glassmorphism)
- [ ] Добавить в `src/styles/globals.css` классы стекла:
  - `.glass-panel`: для основных панелей и дроверов (`backdrop-blur-xl`, `bg-white/[0.08]` на тёмном, `bg-white/[0.7]` на светлом, граница `1px rgba(255,255,255,0.12)`, тень `shadow-2xl`).
  - `.glass-card`: для карточек виджетов и списков (`backdrop-blur-lg`, `bg-white/[0.06]`, hover: `bg-white/[0.1]`, `scale-[1.01]`, плавный transition 150ms).
  - `.glass-pill`: для плавающих кнопок, дока и капсул Speed Dial (`rounded-full`, `backdrop-blur-md`, hover glow).
  - `.glass-input`: для поисковой строки и полей ввода.
  - `.glass-subtle`: для тонких второстепенных плашек.

### 3. UI Primitives нового поколения (`src/ui/primitives/`)
- [ ] **`Button.tsx`**: варианты `primary`, `secondary`, `glass`, `ghost`, `danger`, `outline`; размеры `sm`, `md`, `lg`, `icon`; зона клика $\ge 44 \times 44\text{ px}$.
- [ ] **`Input.tsx`**: стеклянный инпут с поддержкой иконки слева, горячей клавиши справа (`Kbd`), очистки в 1 клик и состояний фокуса/ошибки.
- [ ] **`Select.tsx`**: стилизованный стеклянный выпадающий список.
- [ ] **`Switch.tsx`**: плавный тумблер с анимацией переключения.
- [ ] **`Slider.tsx`**: интерактивный ползунок с заливкой прогресса (для размытия, громкости, затемнения).
- [ ] **`Badge.tsx`**: цветные метки статусов (primary, success, warning, danger, neutral, glass).
- [ ] **`Tooltip.tsx`**: плавающий тултип с поддержкой клавиатурного фокуса.
- [ ] **`Card.tsx`**: базовая стеклянная карточка с поддержкой клика и hover-эффектов.
- [ ] **`Toast.tsx` / `useToast`**: система всплывающих уведомлений для действий пользователя.

### 4. Тестирование и проверка качества
- [ ] Написать unit/компонентные тесты для каждого примитива в `tests/component/primitives/`.
- [ ] Проверить отсутствие ошибок типов: `npx tsc --noEmit`.
- [ ] Проверить чистоту кода линтером: `npm run lint`.
- [ ] Прогнать все тесты: `npm test`.
- [ ] Запустить сборку: `npm run build`.
- [ ] Добавить запись в `docs/CHANGELOG.md`.

---

## Критерии приёмки (Definition of Done)
1. Все 6 шрифтов корректно загружаются и применяются через CSS-переменные.
2. Классы `.glass-panel`, `.glass-card`, `.glass-pill`, `.glass-input` обеспечивают безупречный визуальный эффект стекла с поддержкой тёмной и светлой тем.
3. Все UI primitives доступны с клавиатуры, имеют зону клика $\ge 44 \times 44\text{ px}$ и 100% покрыты тестами.
4. CI-гейты (`tsc`, `lint`, `test`, `build`) зелёные без ошибок и предупреждений.
