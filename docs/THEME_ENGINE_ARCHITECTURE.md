# Архитектура Дизайн-Системы и Theme Engine (Theme Engine Architecture)

## 1. Обзор и Принципы

**Theme Engine** — это ядро визуальной системы DashFlow, построенное на строгой трёхслойной архитектуре токенов, чистой функциональной цветовой математике без доступа к DOM и детерминированной безопасности.

### Ключевые принципы
1. **Чистые функции (Separation of Concerns):** Вся математика цветов (`color.ts`), вывод токенов (`tokens.ts`), валидация CSS (`cssValidator.ts`), санитизация обоев (`wallpaper.ts`) и миграции (`migrations.ts`) являются чистыми функциями без сайд-эффектов и без обращений к DOM (`document`, `window`). Они полностью изолированы и покрыты быстрыми unit-тестами.
2. **Единая точка монтирования в DOM:** Единственный модуль, имеющий право взаимодействовать с `document.head` и `document.documentElement` — это `applyTheme.ts`.
3. **Безопасность по умолчанию:** Пользовательский CSS валидируется на отсутствие сетевых утечек (`@import`, сторонние `url()`), скримов и небезопасных протоколов.
4. **Доступность (WCAG 2.1 AA/AAA):** Контраст каждого пресета подтверждён математически. Минимальный интерактивный размер элементов — 44×44 px (Правило 16).
5. **Mobile First и Адаптивность:** Полная поддержка от мобильных устройств (360 px) до 4K мониторов (3840 px) без горизонтального скролла и таблиц на узких экранах.

## 3. Трёхслойная Система Токенов

Токены организованы в `src/styles/tokens.css` и транслируются в Tailwind 4 (`@theme`):

1. **Слой 1 — Структурные токены (не зависят от темы):**
   - Шкала `z-index`: `--z-base: 0`, `--z-card: 10`, `--z-raised: 20`, `--z-dropdown: 30`, `--z-sticky: 40`, `--z-overlay: 50`, `--z-modal: 60`, `--z-popover: 70`, `--z-toast: 80`.
   - Шкала скруглений (`--radius-sm: 8px`, `--radius-md: 12px`, `--radius-lg: 16px`, `--radius-xl: 24px`, `--radius-full: 9999px`).
   - Тайминги анимаций (`--duration-fast: 150ms`, `--duration-normal: 200ms`, `--duration-slow: 250ms`, кривая `--ease-expo: cubic-bezier(0.16, 1, 0.3, 1)`). Все анимации отключены при `prefers-reduced-motion: reduce`.
   - Шкала отступов: целочисленные шаги Tailwind (0.5=2px, 1=4px, 2=8px, 3=12px, 4=16px, 6=24px, 8=32px, 12=48px, 16=64px).

2. **Слой 2 — Семантические токены темы (`--dashflow-*`):**
   - 24 ключевых цвета: `canvas`, `surface`, `surfaceHover`, `surfaceActive`, `fg`, `fgMuted`, `fgDim`, `line`, `lineHover`, `primary`, `primaryHover`, `primaryActive`, `primaryFg`, `secondary`, `secondaryHover`, `secondaryFg`, `accent`, `accentFg`, `danger`, `dangerFg`, `warning`, `warningFg`, `success`, `successFg`, а также `glassBg` и `glassLine`.
   - Скаляры: `--dashflow-radius`, `--dashflow-font-sans`, `--dashflow-font-mono`.

3. **Слой 3 — Псевдонимы совместимости:**
   - `--color-bg`, `--color-surface`, `--color-primary`, `--color-text`, `--glass-bg`, `--shadow-1`, `--shadow-2`, `--shadow-3` для плавного взаимодействия и обратной совместимости.

## 4. Цветовая Математика и Контраст WCAG 2.1 (`color.ts`)

- Все вычисления проводятся в sRGB с нормализацией компонент `[0, 1]` с плавающей точкой (`Rgba`).
- **Относительная яркость ($L$):**
  $$L = 0.2126 \cdot R_{lin} + 0.7152 \cdot G_{lin} + 0.0722 \cdot B_{lin}$$
  где гамма-коррекция: $C_{lin} = C / 12.92$ при $C \le 0.04045$, иначе $((C + 0.055) / 1.055)^{2.4}$.
- **Контраст по WCAG 2.1:**
  $$\text{Ratio} = \frac{L_1 + 0.05}{L_2 + 0.05}$$
- **Плющение альфа-канала (`flatten`):**
  $$C_{flat} = \alpha \cdot C_{fg} + (1 - \alpha) \cdot C_{bg}$$
  Позволяет достоверно измерять контраст полупрозрачных поверхностей (`glassBg`, `surfaceHover`) на фоне `canvas`.

## 6. Безопасность и Валидация

### Валидатор Custom CSS (`cssValidator.ts`)
- Ограничение размера: не более 50 000 символов (`MAX_CSS_LENGTH`).
- Блокировка директивы `@import` (защита от сетевых утечек IP пользователя).
- Блокировка внешних протоколов в `url()` и `@font-face`: разрешены только `data:`, `chrome-extension:` и опционально `https:` при включенном тумблере `allowExternalCss`.
- Блокировка устаревших XSS-векторов (`behavior:`, `-moz-binding:`).

### Валидатор Обоев (`wallpaper.ts`)
- Разрешены только безопасные протоколы: `https:`, `data:`, `chrome-extension:`.
- Запрещены `http:`, `javascript:`, `file:`, непарные кавычки и управляющие символы.
- Автоматический расчет затемнения `--app-scrim` (от 0.0 до 0.9, по умолчанию 0.3) для сохранения читаемости текста поверх фото-обоев.

## 7. Компоненты UI

Дизайн-система построена на атомарном компонентном подходе в `src/ui/`:

1. **`src/ui/primitives/`:**
   - `Button`: варианты `primary`, `secondary`, `ghost`, `danger`, `glass`; размеры `sm`, `md`, `lg`; зона нажатия $\ge 44 \times 44$ px.
   - `Input`: доступное поле ввода с иконкой, `aria-invalid`, `aria-describedby` для ошибок.
   - `Switch`: нативный `<button role="switch" aria-checked>` с поддержкой клавиатуры (Space, Enter).
   - `Slider`: доступный ползунок диапазона с лейблом и выводом единиц.
   - `Tooltip`: всплывающая подсказка с поддержкой наведения и клавиатурного фокуса.
   - `Badge`: метки статусов на семантических цветах темы.
2. **`src/ui/overlays/`:**
   - `Modal`: диалоговое окно с `role="dialog"`, `aria-modal="true"`, анимацией масштабирования.
   - `Drawer`: выкатная боковая панель с плавной анимацией.
   - `Dropdown`: контекстное меню с клавиатурной навигацией.
   - `useFocusTrap`: хук удержания фокуса внутри модалок (Tab / Shift+Tab), закрытия по `Escape` и возврата фокуса на вызвавший элемент при закрытии.
3. **`src/ui/feedback/`:**
   - `Spinner`: индикатор загрузки с `role="status"` и доступным текстом для screen reader.
   - `Skeleton`: анимированный плейсхолдер с `aria-hidden="true"`.
   - `EmptyState`: заглушка пустого состояния с иконкой и действием.
   - `ErrorState`: блок ошибки с `role="alert"` и кнопкой повтора.
4. **`src/features/appearance/`:**
   - `PresetGrid`: сетка выбора готовых тем с бейджами контраста.
   - `WallpaperPicker`: выбор фото-обоев и управление затемнением scrim.
   - `CustomCssEditor`: редактор пользовательского CSS с проверкой безопасности и счетчиком символов.
   - `AppearanceModal`: единое окно настройки тем с вкладками.
