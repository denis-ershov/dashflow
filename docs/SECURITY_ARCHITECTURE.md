# Архитектура Безопасности (Security Architecture)

## 1. Общие Принципы Безопасности

Проект **DashFlow** спроектирован по стандарту **Security by Design** в строгом соответствии с требованиями безопасности Google Chrome Extension Manifest V3.

```text
┌─────────────────────────────────────────────────────────────┐
│                    Chrome MV3 Security                      │
├─────────────────────────────────────────────────────────────┤
│  Content Security Policy (CSP)                              │
│  - script-src 'self'; object-src 'self'                     │
│  - Никакого inline JS или eval()                            │
├─────────────────────────────────────────────────────────────┤
│  Data Isolation & Access Control                            │
│  - Все пользовательские данные остаются локально            │
│  - Никаких API-ключей в коде фронтенда                     │
├─────────────────────────────────────────────────────────────┤
│  Plugin Sandbox Host                                        │
│  - Сторонние плагины исполняются в <iframe sandbox>         │
│  - Строго ограниченный RPC протокол (postMessage)           │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. Защита от Угрозы XSS и CSS Инъекций

1. **Санитаризация Пользовательского CSS:** Кастомный CSS проверяется перед инъекцией в DOM-дерево.
2. **Безопасный Рендеринг:** Вся текстовая информация и данные закладок рендерятся через React безопасный escape механизмы без прямого использования `dangerouslySetInnerHTML`.
3. **Минимальные Привилегии (Principle of Least Privilege):** В `manifest.json` запрашиваются только критически необходимые разрешения (`storage`, `bookmarks`).

---

## 3. Изоляция Данных и Локальность

- 100% данных (задачи, заметки, конфигурации тем, положение виджетов) хранятся **исключительно на устройстве пользователя** через `chrome.storage.local` и `IndexedDB`.
- Запросы к внешним API (например, погода от Open-Meteo) передают только географические координаты без персональных данных пользователя.
