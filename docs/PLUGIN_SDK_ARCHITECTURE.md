# Архитектура Плагинов, Песочницы и Прав Доступа (Plugin SDK & Sandbox Architecture)

## 1. Обзор Платформенной Архитектуры

В **DashFlow 2.0** система расширений построена на **декларативных JSON-манифестах** в строгом соответствии с политикой Chrome Manifest V3 (запрет на выполнение удаленного нескомпилированного JavaScript кода, ADR-001, ADR-014).

```text
┌─────────────────────────────────────────────────────────────┐
│                       Marketplace                           │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ Marketplace Catalog (Встроенные виджеты + Плагины)    │  │
│  └───────────────────────────┬───────────────────────────┘  │
│                              │                              │
│                              ▼                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ PermissionConsentModal (Подтверждение прав перед уст.) │  │
│  └───────────────────────────┬───────────────────────────┘  │
│                              │                              │
│                              ▼                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ usePluginStore & WidgetRegistry (Динамическая регистр.)│  │
│  └───────────────────────────┬───────────────────────────┘  │
└──────────────────────────────┼──────────────────────────────┘
                               │
                ┌──────────────┴──────────────┐
                ▼                             ▼
┌───────────────────────────────┐ ┌───────────────────────────────┐
│     Шаблонные Виджеты         │ │     PluginHost (Sandbox)      │
│  - RssWidget (тип 'rss')      │ │  - sandbox="allow-scripts"    │
│  - IframeWidget (тип 'embed') │ │  - origin: 'null'             │
│  - QuickLinks (тип 'links')   │ │  - SandboxBridge RPC (Window) │
└───────────────────────────────┘ └───────────────────────────────┘
```

---

## 2. Декларативные Типы Плагинов (`DeclarativePluginType`)

1. **`rss`:** Пользовательская RSS/Atom-лента с HTTPS источником. Отображается через `RssWidget`.
2. **`embed`:** Встраиваемый веб-сервис или веб-приложение по безопасному HTTPS адресу через `IframeWidget`.
3. **`links`:** Набор закладок и быстрых ссылок через `QuickLinksWidget`.
4. **`api`:** Шаблонный виджет данных со стороннего REST API через изолированный хост `PluginHost`.

---

## 3. Безопасный RPC-мост Песочницы (`SandboxBridge.ts`)

- `iframe` хоста монтируется с атрибутом `sandbox="allow-scripts"` (СТРОГО без `allow-same-origin`, ADR-007, ADR-014).
- Фрейм получает `origin: "null"`.
- Проверка отправителя выполняется по ссылке на окно: `event.source === iframe.contentWindow`.
- Изоляция хранилища: ключи автоматически префиксируются как `dashflow_plugin_${pluginId}_${key}`, исключая коллизии и Path Traversal.
- Проверка разрешений в точке вызова: доступ к операциям проверяется через `PermissionManager.hasPermission()`.

---

## 4. Модель Разрешений (Permissions Consent Flow, ADR-015)

- `storage`: предоставляется изолированно по умолчанию.
- `network`, `bookmarks`, `geolocation`: чувствительные права, требующие явного подтверждения пользователя через `PermissionConsentModal` перед установкой.
- Выданные согласия хранятся в `STORAGE_KEYS.PERMISSION_GRANTS` с возможностью отзыва в настройках.
