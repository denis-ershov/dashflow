# Архитектура SDK Плагинов и Песочницы (Plugin SDK & Sandbox)

## 1. Обзор Платформенной Архитектуры

**DashFlow** предоставляет публичный SDK для сторонних разработчиков, позволяющий создавать новые виджеты без доступа к внутреннему исходному коду расширения.

```text
┌─────────────────────────────────────────────────────────────┐
│                       Marketplace                           │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ Marketplace Catalog (Категории, Фильтры, Установка)    │  │
│  └───────────────────────────┬───────────────────────────┘  │
│                              │                              │
│                              ▼                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ PluginHost (Sandboxed Iframe Execution)               │  │
│  │  - Sandbox: allow-scripts                             │  │
│  │  - Secure postMessage RPC Protocol                    │  │
│  └───────────────────────────┬───────────────────────────┘  │
└──────────────────────────────┼──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                        WIDGET SDK                           │
│  ┌───────────────┐ ┌───────────────┐ ┌───────────────┐      │
│  │ Storage API   │ │ Events API    │ │ UI API        │      │
│  │ (get, set)    │ │ (on, emit)    │ │ (Card, Button)│      │
```

## 2. Безопасность и CSP в Manifest V3

В соответствии с требованиями Google Chrome Manifest V3, сторонний нескомпилированный JavaScript не может выполняться в контексте основного расширения (`eval` / `new Function` заблокированы).

Поэтому исполнение плагинов организовано по следующей модели:
1. **Изолированный Sandbox Host:** Плагин загружается в песочницу `iframe` с флагом `sandbox="allow-scripts"`.
2. **RPC по протоколу PostMessage:** Плагин запрашивает вызовы API (чтение хранилища, логирование, отправка событий) исключительно через асинхронные сообщения `postMessage`.
3. **Разрешения (Permissions):** Каждый плагин запрашивает только необходимые привилегии (`network`, `storage`, `notifications`, `bookmarks`).

## 3. Набор SDK API (`@dashflow/sdk`)

- `storage`: Защищенный изолированный доступ к хранилищу виджета `storage.get()`, `storage.set()`, `storage.remove()`.
- `events`: Подписка и отправка событий системной шины `events.on()`, `events.emit()`.
- `ui`: Набор стандартных компонентов (`Card`, `Button`, `Input`, `Tooltip`).
- `settings`: Декларативное описание полей настроек виджета.
