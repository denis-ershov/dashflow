# Чеклист соответствия нормативным требованиям и политикам магазинов (Compliance Checklist)

**Дата создания:** 30 сентября 2026  
**Версия:** 1.0.0  
**Статус:** Verified

---

## 1. Chrome Web Store Developer Program Policies

| Требование | Статус | Как реализовано в DashFlow |
|---|---|---|
| **Single Purpose Policy** | ✅ Соответствует | Превращение новой вкладки (New Tab) в настраиваемый продуктивный дашборд. Нет скрытых или посторонних функций. |
| **User Data Policy (Privacy)** | ✅ Соответствует | Ссылки на [`PRIVACY.md`](../PRIVACY.md) и [`PRIVACY_EN.md`](../PRIVACY_EN.md). Все данные хранятся локально, нулевая телеметрия. |
| **Permissions Justification** | ✅ Соответствует | Запрашиваются минимальные права (`storage`). Чувствительные права (`bookmarks`, `geolocation`, `tabs`) опциональны и требуют согласия через `PermissionConsentModal`. |
| **No Remote Code Execution (Manifest V3)** | ✅ Соответствует | Нет `eval()`, нет загрузки скриптов с внешних CDN. Все компоненты и звуки собраны локально в бандл. |
| **Content Security Policy (CSP)** | ✅ Соответствует | Строгий CSP: `script-src 'self'; object-src 'self'`. Iframe изолирован без `allow-same-origin`. |
| **Monetization & Ads Transparency** | ✅ Соответствует | DashFlow распространяется бесплатно, не содержит рекламы, баннеров, аффилированных ссылок или скрытых крипто-майнеров. |

## 2. Mozilla Add-ons (AMO) Review Guidelines

| Требование | Статус | Как реализовано в DashFlow |
|---|---|---|
| **Source Code Submission** | ✅ Соответствует | При сборке релиза автоматически формируется архив исходного кода `.output/dashflow-{version}-sources.zip`. |
| **Gecko ID** | ✅ Соответствует | `wxt.config.ts` содержит корректную секцию `browser_specific_settings.gecko` с ID `dashflow@addon` и `strict_min_version: 109.0`. |
| **No Obfuscated Code** | ✅ Соответствует | Исходный код открыт (GPL-3.0), минификация Vite выполняется стандартными средствами без кастомной обфускации. |

## 3. GDPR (Общий регламент по защите данных ЕС)

| Статья / Принцип | Статус | Реализация в DashFlow |
|---|---|---|
| **Privacy by Design (ст. 25)** | ✅ Реализован | Все заметки, задачи, настройки хранятся в изолированном хранилище `chrome.storage.local` на устройстве пользователя. |
| **Право на доступ (ст. 15)** | ✅ Реализован | Пользователь видит все свои данные в интерфейсе и может экспортировать их в читаемый JSON-файл в один клик. |
| **Право на забвение (ст. 17)** | ✅ Реализован | Удаление расширения или очистка данных в настройках браузера физически и безвозвратно удаляет всю базу данных. |
| **Право на переносимость (ст. 20)** | ✅ Реализован | Экспорт полного состояния в формате `.json` (`ImportExportModal.tsx`). |
| **Минимизация данных (ст. 5)** | ✅ Реализован | Никакие персональные идентификаторы, IP-адреса или cookies не передаются разработчикам. |

---

## 4. CCPA (Калифорнийский закон о конфиденциальности потребителей)

- **"Do Not Sell My Personal Information"**: DashFlow никогда не продавал, не продает и не планирует продавать пользовательские данные третьим лицам.
- **Отсутствие трекеров**: В бандле отсутствуют Google Analytics, Yandex Metrika, Facebook Pixel и любые другие сторонние SDK.
