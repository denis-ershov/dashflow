# ADR-011: Изоляция сбоев виджетов через WidgetShell и ErrorBoundary

## Статус
Принято (Accepted)

## Контекст
В legacy-коде отсутствовала граница ошибок вокруг виджетов. Любой runtime-сбой или ошибка парсинга в компоненте виджета приводили к падению всего React-дерева приложения и белому экрану на New Tab странице (нарушение Правила 25).

## Решение
1. Разработать единую оболочку виджета `WidgetShell` (`src/core/widget/WidgetShell.tsx`), в которую инкапсулирован `WidgetErrorBoundary`.
2. При сбое рендеринга виджета `WidgetErrorBoundary` выводит аккуратную карточку `ErrorState` с кнопкой повтора и заголовком виджета.
3. Ошибка безопасно логируется в консоль без сериализации настроек пользователя (предотвращение утечки персональных данных).
4. Оболочка инкапсулирует три стандартных типа поверхностей DashFlow: `chromeless`, `panel`, `tiles`.

## Последствия
- Полная устойчивость дашборда: сбой в одном виджете изолируется локально.
- Единообразное поведение заголовков, ручек перетаскивания и меню настроек для всех типов виджетов.
