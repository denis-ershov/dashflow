# ADR-014: Декларативная система плагинов и безопасность Sandbox Bridge

## Статус
Принято (Accepted)

## Контекст
В Manifest V3 запрещено выполнение удаленного кода (`scriptUrl` / `eval`). Ранее `PluginHost` использовал небезопасный глобальный обработчик `postMessage` без проверки окна источника и без изоляции ключей хранилища, а также объявлял неиспользуемый `scriptUrl`.

## Решение
1. Перевести всю систему расширений DashFlow на **декларативные JSON-манифесты** (`rss`, `embed`, `links`, `api`) без внешнего исполняемого JavaScript.
2. Внедрить строгий валидатор манифестов `validatePluginManifest`, проверяющий HTTPS URL, допустимые размеры и разрешенные привилегии.
3. Реализовать класс `SandboxBridge` для изолированного обмена сообщениями:
   - Проверка источника строго по объекту `Window` фрейма (`event.source === expectedWindow`).
   - Изоляция ключей хранилища с префиксом `dashflow_plugin_${pluginId}_`.
   - Запрет `allow-same-origin` во фреймах песочницы.

## Последствия
- Полное соответствие требованиям Chrome Web Store для Manifest V3.
- Исключение межсайтового скриптинга и несанкционированного доступа к хранилищу других виджетов.
