# ADR-017: Единая модель Item в отдельной базе IndexedDB

**Дата:** 2026-10-30 · **Статус:** принято

## Проблема

Содержимое виджетов хранится в разрозненных ключах `chrome.storage.local` (`dashflow_widget_todo_items_<id>` и т. п.) в формате, который знает только свой виджет. Для Inbox, досок, напоминаний, поиска, агентов и синхронизации нужна общая модель, запросы по полям и журнал изменений.

## Варианты

1. **Расширить текущие ключи.** Минимум работы, но нет запросов, транзакций и журнала; каждый новый виджет — новый формат.
2. **Одна сущность Item в IndexedDB** (`idb` уже в зависимостях): индексы, транзакции, большой объём, доступ из сервис-воркера.
3. **Встраиваемая БД (SQLite WASM, PGlite, RxDB).** Мощные запросы и синхронизация из коробки, но +0,5–1,5 МБ к пакету, сложнее CSP (`wasm-unsafe-eval`) и ревью в магазинах.

## Решение

Вариант 2: `Item` с полем `kind`, база `dashflow_items` (stores `items`, `boards`, `changes`), репозиторий с валидацией на границе, журнал изменений в той же транзакции, уведомления через `BroadcastChannel`.

**Порядок элементов** — дробные ключи через `fractional-indexing` (Rocicorp, CC0, ≈2 КБ, без зависимостей). Собственная реализация «середины» проще, но при добавлении в конец ключ растёт линейно (≈1 символ на 5 вставок); у библиотеки — логарифмически (1 000 вставок — 3 символа).

**Тесты** — `fake-indexeddb` (dev-зависимость): настоящая семантика IndexedDB в jsdom без моков.

## Последствия

- Плюсы: один формат для UI, импорта, агентов и Hub; отмена и синхронизация строятся на журнале; данные доступны воркеру для напоминаний.
- Минусы: запросы по нескольким полям фильтруются в памяти (приемлемо до ~10 000 записей; дальше — составные индексы); миграция существующих данных (шаг 1.3) — главный риск этапа 1.
- Новые зависимости: `fractional-indexing` (runtime), `fake-indexeddb` (dev).

## Альтернативы на будущее

Если объёмы вырастут на порядок или понадобятся сложные запросы — SQLite WASM в offscreen-документе; модель Item и репозиторий как граница позволяют заменить хранилище без изменения виджетов.
