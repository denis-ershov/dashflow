# ADR-012: Ленивая загрузка и разделение кода манифестов виджетов (Code Splitting)

## Статус
Принято (Accepted)

## Контекст
В legacy-коде все 12 виджетов импортировались статически в точку входа дашборда. Это раздувало начальный бандл новой вкладки браузера, замедляя время первой отрисовки (Time to Interactive).

## Решение
1. В контракте манифеста виджета `WidgetDefinition<S>` поле `component` заменено на асинхронную функцию загрузки:
   ```ts
   load: () => Promise<{ default: ComponentType<WidgetProps<S>> }>
   ```
2. Все встроенные манифесты виджетов используют синтаксис `load: () => import('./WidgetComponent').then(m => ({ default: m.WidgetComponent }))`.
3. Реестр манифестов регистрирует только легковесные метаданные (~1 КБ), а тяжелый код виджетов и их внешние библиотеки подтягиваются по требованию.

## Последствия
- Быстрая инициализация страницы (< 2 сек по ТЗ).
- Полная изоляция зависимостей между виджетами.
