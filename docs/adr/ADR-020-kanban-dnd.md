# ADR-020. Сортировка карточек Kanban

Статус — принято 2026-11-23.

## Контекст

Карточки нужно переставлять внутри колонки и между колонками мышью, касанием и клавиатурой. Результат перемещения должен сохраняться в Item и быть доступен после перезагрузки.

## Решение

Использовать `@dnd-kit/core` 6.3.1, `@dnd-kit/sortable` 10.0.0 и `@dnd-kit/utilities` 3.2.2. Эти пакеты совместимы с React проекта, распространяются по MIT и используются в лениво загружаемом виджете. Для мыши и касания применяется датчик координат. Для клавиатуры вычисляются логические соседние позиции, включая пустые колонки. Действия доступны также из панели карточки.

В UI управляются подсветка цели, объявления и состояние WIP. Превышение WIP показывается как предупреждение. При отпускании карточки одна команда `item.move` проверяет версию и актуальность соседей, затем сохраняет порядок и статус в IndexedDB.

## Альтернативы и ограничения

Нативное HTML Drag and Drop потребовало бы отдельной реализации для касаний и клавиатуры. Собственная обработка Pointer Events потребовала бы самостоятельно поддерживать коллизии и отмену жестов. Выбранная библиотека добавляет код в чанк Kanban. Совместимость со скринридерами проверяется отдельно от клавиатурного автотеста.
