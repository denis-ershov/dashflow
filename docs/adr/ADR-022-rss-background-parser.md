# ADR-022. Разбор RSS в фоновом контексте

Статус — принято 2026-11-24.

## Контекст

RSS и Atom должны обновляться при закрытых вкладках. В Chrome MV3 сервис-воркер не предоставляет браузерный `DOMParser`, которым пользовался виджет.

## Решение

Общий парсер `src/core/feeds/parser.ts` использует `@xmldom/xmldom` 0.9.12 под MIT. Пакет работает без браузерного DOM, имеет ноль зависимостей и занимает около 440 КБ в распакованном виде. Версия закреплена в lock-файле. Парсер принимает RSS, RDF и Atom, ограничивает вход 2 МиБ, отклоняет DTD и сущности и останавливается при ошибках разбора. Текст и проверенные HTTP(S)-ссылки передаются в UI в виде данных.

Фон обновляет кеш раз в 30 минут только для включённых лент с выданными разрешениями. Читалка, виджет и дайджест используют кеш. Для лент с редиректом пользователь указывает конечный URL, чтобы разрешение запрашивалось к фактическому хосту.

## Альтернативы и ограничения

Отдельная страница для разбора XML потребовала бы дополнительного браузерного механизма и усложнила жизненный цикл фона. Два независимых парсера увеличили бы риск расхождения RSS и Atom между вкладкой и воркером. Смена парсера добавляет в сборку библиотеку XML, которая требует регулярного обновления.
