# Архитектура сетки, Hero-зоны и навигации (Layout & Navigation Architecture)

## 1. Концепция DashFlow 3.0: Dual Experience (Zen & Modular)

Интерфейс DashFlow 3.0 спроектирован по принципу **Reflect Ultra-Aesthetics** и **Mobile First**:

```
+-------------------------------------------------------------------------+
|                              [ОБОИ + РАЗМЫТИЕ]                          |
|                                                                         |
|                         [SmartGreeting: Приветствие]                    |
|                        [HeroClock: Часы + Русская дата]                 |
|                      [SearchBar2: Мультипоисковая строка]               |
|                    [YearProgression: Индикатор прогресса года]          |
|                                                                         |
|                  [SpeedDialGrid: Стеклянные капсулы сайтов]             |
|                                                                         |
|  ------------------ ТОЛЬКО В РЕЖИМЕ MODULAR DASHBOARD ----------------  |
|               [GridEngine: Адаптивная модульная сетка виджетов]         |
|                                                                         |
|            [FloatingDock: Плавающая стеклянная капсула управления]      |
|           (Режим Zen/Dashboard | (+) | [🔍] | [🎨] | [🔊] | [⚙️])      |
+-------------------------------------------------------------------------+
```

### Режимы отображения (`layoutMode`):
1. **Режим Zen (Фокус):**
   - Максимальный минимализм и эстетика.
   - Отображаются: обои, центральная Hero-зона (часы, приветствие, мультипоиск, прогресс года), быстрые ссылки Speed Dial и плавающий Floating Dock.
   - Идеально для концентрации без визуального шума.
2. **Режим Modular Dashboard (Виджеты):**
   - Полная функциональность с модульной сеткой `GridEngine` (до 12 виджетов одновременно).
   - Сетка располагается ниже Hero-зоны с бесшовным скроллом.

---

## 2. Центральная Hero-зона (`src/features/hero/`)

- **`HeroClock`:** 5 стилей часов (`digital`, `minimal`, `serif`, `flip`, `mono`), формат 12/24ч, секунды, русская локализация даты.
- **`SmartGreeting`:** Приветствие в зависимости от времени суток (*«Доброе утро»*, *«Добрый день»*, *«Добрый вечер»*, *«Доброй ночи»*) с персонализацией по имени.
- **`SearchBar2`:** Стеклянная поисковая строка с 7 движками (Google, Yandex, DuckDuckGo, Bing, GitHub, YouTube, Perplexity AI), хоткеем `/` и распознаванием прямых URL.
- **`YearProgression`:** Интерактивный индикатор прогресса дня, месяца и года в процентах.

---

## 3. Быстрые закладки Speed Dial (`src/features/speedDial/`)

- Стеклянные капсулы сайтов (`SpeedDialGrid`) с автоматической подгрузкой фавиконок Google Favicon Service (`sz=64`).
- Кнопка быстрого добавления (`AddLinkModal`) с автоопределением названия сайта по домену.
- Быстрое удаление ссылок при наведении через всплывающую иконку корзины.

---

## 4. Плавающий бар управления (`FloatingDock`)

- Расположен по центру снизу экрана (`fixed bottom-6 left-1/2 -translate-x-1/2`).
- Стеклянная капсула `.glass-pill` с эффектом `backdrop-blur-md` и мягкой тенью.
- Быстрый доступ:
  - Переключение режимов Zen / Dashboard;
  - Каталог виджетов (+);
  - Командная строка Ctrl+K;
  - Темы оформления и обои;
  - Звуки природы (Ambient Soundscapes) с живым индикатором воспроизведения;
  - Редактирование сетки (замок/разблокировка);
  - Настройки расширения.
- Все интерактивные кнопки имеют минимальный размер $44 \times 44$ px и тултипы.

## 5. Адаптивная сетка `GridEngine` и `ResponsiveGridLayout`

Сетка разделена на 5 брейкпоинтов:

| Брейкпоинт | Минимальная ширина | Колонки (База 12) | Колонки (База 16) | Колонки (База 24) |
|---|---|---|---|---|
| `xl` | $\ge 1200$ px | 12 | 16 | 24 |
| `lg` | 900–1199 px | 8 | 12 | 16 |
| `md` | 640–899 px | 6 | 8 | 8 |
| `sm` | 360–639 px | 4 | 4 | 4 |
| `xs` | $< 360$ px | 2 | 2 | 2 |

### Вычисление высоты ячейки (`useGridMetrics`):
- Высота ряда рассчитывается динамически для сохранения пропорций:
  $$\text{cellWidth} = \frac{\text{containerWidth} - (\text{cols} - 1) \times \text{gap} - 2 \times \text{padding}}{\text{cols}}$$
- Ограничение: $\text{rowHeight} \in [72\text{ px}, 140\text{ px}]$.

## 6. Пространства и глобальный поиск

- Док открывает `SpacesModal` для выбора, создания пространства и подтверждения удаления. У активного пространства есть отметка. Переключение доступно из палитры и клавишами `Alt+1…9` вне ввода, если сочетание доставляет браузер.
- В форме создания по умолчанию выбрана пустая сетка. Шаблон «Утро» открывает модульную раскладку с Hero, дайджестом и повесткой. Шаблон «Фокус» открывает Canvas со списком задач и Pomodoro. Каждый запуск шаблона создаёт новые экземпляры виджетов и адаптивные раскладки. В качестве имени можно оставить локализованное название шаблона или указать своё.
- Пространства из шаблонов хранят собственный режим экрана. Переключатель режима меняет активное пространство с собственным режимом либо общий режим для старых и пустых пространств. Экспорт и импорт сохраняют собственные режимы и идентификаторы экземпляров в снимке v3.
- Удаление пространства, виджета или ссылки Speed Dial добавляет запись в общую историю отмены. Тост связан с конкретной записью истории. Отмена восстанавливает исходную сущность и её место, оставляя позднейшие изменения соседних элементов и текущий выбор пространства.
- `useDashboardStore` хранит пространства и указатель активной сетки. Переключение пересоздаёт `GridEngine` с её виджетами и закрывает редактор. Асинхронная привязка Item обновляет настройки исходного экземпляра по его id, даже когда активное пространство сменилось. Поведение сохранения описано в [архитектуре хранилища](STORAGE_ARCHITECTURE.md).
- `CommandPalette` доступна с кнопки поиска в доке и по `Ctrl+K` / `Cmd+K`. Результаты сгруппированы по записям Item, пространствам, виджетам и командам. Стрелки меняют выбор, Enter открывает результат, Escape закрывает окно и возвращает фокус.
- `useWorkspaceIndex` читает активные Item из IndexedDB после переноса данных. `workspaceSearch.ts` индексирует заголовок, тело, теги и URL. Порядок совпадений: точное, начало поля, вхождение. Внутри каждого уровня первыми идут свежие записи. Палитра показывает до 12 записей Item.
- При выборе виджета, заметки или видимой задачи `useSearchDestination` открывает нужную сетку, переводит фокус и кратко подсвечивает цель. Для записей без доступной цели открывается карточка, ссылки http/https открываются отдельно. Карточка выводит тело записи обычным текстом.
## Представление пространства

Пространство может сохранить собственные настройки Hero, URL обоев и затемнение. При отсутствии значений действуют прежние общие настройки. Поиск в Hero и переключатели в настройках записывают изменения в активное пространство. Вкладка обоев позволяет убрать изображение только из текущего пространства или снова использовать общий фон.

Репозиторий раскладки валидирует поля Hero и URL обоев при импорте и чтении снимка. Формат снимка остаётся v3, экспорт 3.0 сохраняет настройки в `spaces`. Ранее экспортированные снимки наследуют общие настройки. При откате на сборку без этой возможности общий фон и настройки Hero остаются доступны.
