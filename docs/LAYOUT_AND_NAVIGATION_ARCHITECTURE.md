# Архитектура сетки, Hero-зоны и навигации (Layout & Navigation Architecture)

## 1. Концепция DashFlow 3.0: Dual Experience (Zen & Modular)

Интерфейс DashFlow 3.0 спроектирован по принципу **Reflect Ultra-Aesthetics** и **Mobile First**:

```
+-------------------------------------------------------------------------+
|                              [ОБОИ + РАЗМЫТИЕ]                          |
|                                                                         |
|                         [SmartGreeting: Приветствие]                    |
|                        [HeroClock: Часы + Русская дата]                 |
|                      [SearchBar2: Мультипоисковая строка]               |
|                    [YearProgression: Индикатор прогресса года]          |
|                                                                         |
|                  [SpeedDialGrid: Стеклянные капсулы сайтов]             |
|                                                                         |
|  ------------------ ТОЛЬКО В РЕЖИМЕ MODULAR DASHBOARD ----------------  |
|               [GridEngine: Адаптивная модульная сетка виджетов]         |
|                                                                         |
|            [FloatingDock: Плавающая стеклянная капсула управления]      |
|           (Режим Zen/Dashboard | (+) | [🔍] | [🎨] | [🔊] | [⚙️])      |
+-------------------------------------------------------------------------+
```

### Режимы отображения (`layoutMode`):
1. **Режим Zen (Фокус):**
   - Максимальный минимализм и эстетика.
   - Отображаются: обои, центральная Hero-зона (часы, приветствие, мультипоиск, прогресс года), быстрые ссылки Speed Dial и плавающий Floating Dock.
   - Идеально для концентрации без визуального шума.
2. **Режим Modular Dashboard (Виджеты):**
   - Полная функциональность с модульной сеткой `GridEngine` (до 12 виджетов одновременно).
   - Сетка располагается ниже Hero-зоны с бесшовным скроллом.

---

## 2. Центральная Hero-зона (`src/features/hero/`)

- **`HeroClock`:** 5 стилей часов (`digital`, `minimal`, `serif`, `flip`, `mono`), формат 12/24ч, секунды, русская локализация даты.
- **`SmartGreeting`:** Приветствие в зависимости от времени суток (*«Доброе утро»*, *«Добрый день»*, *«Добрый вечер»*, *«Доброй ночи»*) с персонализацией по имени.
- **`SearchBar2`:** Стеклянная поисковая строка с 7 движками (Google, Yandex, DuckDuckGo, Bing, GitHub, YouTube, Perplexity AI), хоткеем `/` и распознаванием прямых URL.
- **`YearProgression`:** Интерактивный индикатор прогресса дня, месяца и года в процентах.

---

## 3. Быстрые закладки Speed Dial (`src/features/speedDial/`)

- Стеклянные капсулы сайтов (`SpeedDialGrid`) с автоматической подгрузкой фавиконок Google Favicon Service (`sz=64`).
- Кнопка быстрого добавления (`AddLinkModal`) с автоопределением названия сайта по домену.
- Быстрое удаление ссылок при наведении через всплывающую иконку корзины.

---

## 4. Плавающий бар управления (`FloatingDock`)

- Расположен по центру снизу экрана (`fixed bottom-6 left-1/2 -translate-x-1/2`).
- Стеклянная капсула `.glass-pill` с эффектом `backdrop-blur-md` и мягкой тенью.
- Быстрый доступ:
  - Переключение режимов Zen / Dashboard;
  - Каталог виджетов (+);
  - Командная строка Ctrl+K;
  - Темы оформления и обои;
  - Звуки природы (Ambient Soundscapes) с живым индикатором воспроизведения;
  - Редактирование сетки (замок/разблокировка);
  - Настройки расширения.
- Все интерактивные кнопки имеют минимальный размер $44 \times 44$ px и тултипы.

## 5. Адаптивная сетка `GridEngine` и `ResponsiveGridLayout`

Сетка разделена на 5 брейкпоинтов:

| Брейкпоинт | Минимальная ширина | Колонки (База 12) | Колонки (База 16) | Колонки (База 24) |
|---|---|---|---|---|
| `xl` | $\ge 1200$ px | 12 | 16 | 24 |
| `lg` | 900–1199 px | 8 | 12 | 16 |
| `md` | 640–899 px | 6 | 8 | 8 |
| `sm` | 360–639 px | 4 | 4 | 4 |
| `xs` | $< 360$ px | 2 | 2 | 2 |

### Вычисление высоты ячейки (`useGridMetrics`):
- Высота ряда рассчитывается динамически для сохранения пропорций:
  $$\text{cellWidth} = \frac{\text{containerWidth} - (\text{cols} - 1) \times \text{gap} - 2 \times \text{padding}}{\text{cols}}$$
- Ограничение: $\text{rowHeight} \in [72\text{ px}, 140\text{ px}]$.
