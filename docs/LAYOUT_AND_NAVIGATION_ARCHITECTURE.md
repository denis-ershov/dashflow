# Архитектура сетки и навигации (Layout & Navigation Architecture)

## 1. Структура каркаса и навигационного рельса (`NavRail`)

Каркас приложения DashFlow построен по принципу **Mobile First** с адаптацией под любые экраны (от 360 px до 4K):

```
+-------------------------------------------------------------------------+
| [NavRail (Desktop >= 640px)] | [Рабочая область дашборда (GridEngine)]  |
| - Логотип                   | - ResponsiveGridLayout (5 брейкпоинтов)   |
| - Добавить виджет (+)       | - Адаптивная высота ряда (72-140 px)      |
| - Поиск (Ctrl+K)            | - Оболочки WidgetShell с ErrorBoundary    |
| - Темы оформления           | - Ленивая загрузка LazyWidgetRenderer     |
| - Каталог виджетов          |                                           |
| - Режим правки              |                                           |
| - Настройки                 |                                           |
+-------------------------------------------------------------------------+
| [NavRail (Mobile < 640px)] Нижная панель: (+) [🔍] [🎨] [🛍️] [✏️] [⚙️]  |
+-------------------------------------------------------------------------+
```

### Принципы навигационного каркаса:
1. **Постоянная доступность (Вариант A):** На десктопе рельс прижат к левому краю, ширина 64 px (`w-16`). Элементы управления находятся без обучения, путь курсора минимален.
2. **Mobile First:** На экранах $< 640$ px рельс автоматически трансформируется в нижнюю навигационную панель высотой 64 px (`h-16`), до которой легко достать большим пальцем.
3. **Доступность (WCAG 2.1):** Все зоны нажатия интерактивных элементов имеют размер не менее $44 \times 44$ px (`w-11 h-11`). Поддерживается клавиатурная навигация и кольца фокуса `focus-visible`.

## 2. Адаптивная сетка `GridEngine` и `ResponsiveGridLayout`

Сетка разделена на 5 брейкпоинтов:

| Брейкпоинт | Минимальная ширина | Колонки (База 12) | Колонки (База 16) | Колонки (База 24) |
|---|---|---|---|---|
| `xl` | $\ge 1200$ px | 12 | 16 | 24 |
| `lg` | 900–1199 px | 8 | 12 | 16 |
| `md` | 640–899 px | 6 | 8 | 8 |
| `sm` | 360–639 px | 4 | 4 | 4 |
| `xs` | $< 360$ px | 2 | 2 | 2 |

### Вычисление высоты ячейки (`useGridMetrics`):
- Высота ряда рассчитывается динамически для сохранения пропорций квадрата:
  $$\text{cellWidth} = \frac{\text{containerWidth} - (\text{cols} - 1) \times \text{gap} - 2 \times \text{padding}}{\text{cols}}$$
- Ограничение: $\text{rowHeight} \in [72\text{ px}, 140\text{ px}]$. Это исключает гигантские баннеры на сверхшироких 2K/4K мониторах.

## 3. Режим правки и клавиатурное управление (`useGridKeyboardNav`)

1. **Изолированный режим правки:** Перетаскивание (`isDraggable`) и масштабирование (`isResizable`) активны **только** при `isEditMode = true`. В обычном режиме дашборд статичен, случайные сдвиги исключены, а текст в заметках свободно выделяется.
2. **Управление с клавиатуры:**
   - `Escape`: выход из режима правки.
   - `Стрелки`: перемещение активного виджета на 1 ячейку в соответствующем направлении.
   - `Shift + Стрелки`: изменение ширины/высоты виджета на 1 ячейку.
   - `aria-live="polite"`: озвучивание статуса перемещения скринридерами.
