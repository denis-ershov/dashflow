# Архитектура Сетки и Интерфейса (Layout Engine & UI Architecture)

## 1. Обзор Layout Engine

**Layout Engine** отвечает за адаптивное размещение, перетаскивание (Drag & Drop) и изменение размеров (Resize) виджетов на рабочем столе новой вкладки Chrome.

```text

│                    Dashboard Layout                         │
├─────────────────────────────────────────────────────────────┤
│  Grid Engine (12 / 16 / 24 Columns, Dynamic Gap)            │
│  ┌───────────────────────┐       ┌───────────────────────┐  │
│  │ WidgetCard (3x2)      │       │ WidgetCard (6x4)      │  │
│  │  ├── Widget Header    │       │  ├── Widget Header    │  │
│  │  ├── Content Slot     │       │  ├── Content Slot     │  │
│  │  └── Resize Handles   │       │  └── Resize Handles   │  │
│  └───────────────────────┘       └───────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  Floating Toolbar (Bottom Floating Action Bar)              │
│  Command Palette (Ctrl + K Overlay)                         │
└─────────────────────────────────────────────────────────────┘
```

## 2. Принципы построения Сетки (Grid Mechanics)

1. **Колоночные конфигурации:**
   - **12 колонок (дефолт):** Идеально для большинства экранов от 1280px до 4K.
   - **16 колонок:** Для элитных ультрашироких мониторов и плотной компоновки.
   - **24 колонки:** Максимальная точность позиционирования для продвинутых пользователей.
2. **Динамический расчет координат:**
   - Каждая ячейка вычисляется в процентах от ширины контейнера `(100% - gap * (cols - 1)) / cols`.
   - Высота строки фиксирована (например, 80px), плюс учитывается межэлементный `gap`.
3. **Snap-to-Grid & Collision Prevention:**
   - При перемещении и изменении размера виджет автоматически привязывается к ближайшим координатам сетки.
   - Алгоритм автоматического предотвращения перекрытий смещает нижележащие элементы при необходимости.

## 3. UI Component System (`src/components/ui/`)

В проекте реализована единая атомная библиотека UI-компонентов на основе TailwindCSS v4 и CSS Variables токенов:

- `Button`: Кнопка с вариантами (`primary`, `secondary`, `ghost`, `danger`, `glass`).
- `Input`: Поле ввода с иконками, состоянием ошибки и очистки.
- `Select`: Кастомный выпадающий список.
- `Modal`: Диалоговое окно с фоновым `backdrop-blur`, закрытием по Esc и кнопкой закрытия.
- `Dropdown`: Выпадающее меню для контекстных действий виджета.
- `Switch`: Переключатель (toggle) для настроек.
- `Slider`: Ползунок регулятора (прозрачность, зазоры, размеры).
- `Tooltip`: Всплывающие подсказки при наведении.
- `Toast`: Уведомления системы.
- `CommandPalette`: Командный центр, вызываемый по `Ctrl + K`.
- `FloatingToolbar`: Плавающая панель управления со сниженной нагрузкой на глаза.

---

## 4. UI/UX Стандарты и Адаптивность

- **Pixel Perfect:** Все компоненты используют одинаковые радиусы (`var(--radius-md)`), тени (`var(--shadow-md)`) и межэлементные отступы.
- **Анимации:** Все hover-эффекты и появление модальных окон длятся от 150 до 250 миллисекунд.
- **Accessibility:** Все интерактивные элементы имеют `aria-label`, управляемы с клавиатуры и обладают минимальным размером кликабельной зоны `44x44px`.
