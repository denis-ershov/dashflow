# Архитектура дайджеста

Виджет «Дайджест» открывается из каталога и загружается отдельным модулем. Он показывает последний активный непрочитанный выпуск. Остальные выпуски доступны в архиве, который раскрывает содержимое по запросу. При чтении виджет записывает статус `read` через репозиторий Item. Обновления между вкладками и фоновым воркером передаются штатными событиями Item.

## Сборка «Утра»

По кнопке виджет отправляет фоновому воркеру запрос без пользовательских параметров. Расписание выключено по умолчанию и хранится в локальных настройках расширения. После включения воркер выставляет одноразовый будильник на ближайшие 07:30 по местному времени. Если браузер проснулся после этого часа, воркер собирает выпуск за текущий местный день и планирует следующий запуск. При временном отказе хранилища или будильника воркер пробует проверить расписание снова через минуту.

Воркер последовательно обрабатывает ручные и автоматические запуски. Перед чтением источников он ищет выпуск с техническим тегом `morning-<год>-<месяц>-<день>`, включая записи в архиве и корзине. Повторный запрос использует существующий выпуск. Репозиторий сохраняет новый выпуск как Item вида `digest` со статусом `unread`, заголовком и секциями Markdown в `body`.

## Источники и ограничения

- Погода берётся из кеша виджета. Сводка показывает город и сохранённую температуру в градусах Цельсия или сообщение об отсутствии данных.
- Из Item отбираются открытые задачи со сроком от начала текущего местного дня до начала следующего. В выпуске отображаются первые 30 задач по сроку.
- Из кеша активных RSS-виджетов берутся до восьми заголовков за последние 24 часа. Кеш наполняется при обычной загрузке RSS. Пустой кеш и ошибка его чтения отображаются отдельными сообщениями.

Шаблон сохраняется на выбранном языке в момент сборки. Изменение языка интерфейса применяется к новым выпускам. Markdown-превью формирует React-узлы. HTML остаётся текстом, а ссылки в списках открываются только по HTTP(S) и без передачи контекста вкладки. Дайджест использует существующие права `storage` и `alarms`, локальную базу Item и кеши виджетов.
