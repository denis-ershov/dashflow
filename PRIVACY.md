# Политика конфиденциальности DashFlow

**Последнее обновление:** 30 сентября 2026  
**Версия:** 1.0.0

---

## Введение

DashFlow ("мы", "наше расширение") — это расширение для браузера с открытым исходным кодом, которое превращает новую вкладку в персональный продуктивный дашборд.

Мы серьёзно относимся к вашей конфиденциальности. Эта политика описывает, какие данные собирает DashFlow, как они используются и какие права у вас есть.

---

## Принципы конфиденциальности

1. **Privacy by Design**: Все данные хранятся локально на вашем устройстве.
2. **Нулевая телеметрия**: Мы не собираем аналитику, метрики использования или персональные данные.
3. **Минимизация данных**: Мы запрашиваем только необходимые разрешения для работы функций.
4. **Прозрачность**: Исходный код доступен на GitHub для аудита.
5. **Контроль пользователя**: Вы полностью контролируете свои данные и можете удалить их в любой момент.

---

## Какие данные мы собираем

### 1. Локальные данные (хранятся в браузере)

DashFlow хранит следующие данные **локально** в хранилище браузера (`chrome.storage.local`):

#### Настройки и конфигурация:
- Выбранная тема оформления и обои
- Язык интерфейса (русский/английский)
- Режим отображения (Zen/Modular)
- Настройки часов (формат 12/24ч, стиль)
- Настройки звуков окружения (громкость, выбранный звук)

#### Пользовательский контент:
- Список задач (TODO Widget)
- Заметки (Notes Widget)
- Закладки быстрого доступа (Quick Links Widget)
- Подписки на RSS-ленты (RSS Widget)
- URL для встроенных iframe (Iframe Widget)
- Город для виджета погоды

#### Состояние виджетов:
- Расположение и размеры виджетов на сетке
- Настройки каждого виджета
- Видимость виджетов

#### Технические данные:
- Версия схемы данных (для миграций)
- Timestamp последнего обновления

**Важно:** Все эти данные **никогда не покидают ваше устройство** и не передаются на наши серверы.

---

### 2. Сетевые запросы к внешним API

Некоторые виджеты обращаются к публичным API для получения актуальной информации:

#### Weather Widget (Погода):
- **API:** Open-Meteo (https://api.open-meteo.com)
- **Данные:** Координаты города (широта/долгота) или название города
- **Цель:** Получение прогноза погоды
- **Privacy Policy API:** https://open-meteo.com/en/terms

#### Geolocation (Автоопределение города):
- **API:** BigDataCloud (https://api.bigdatacloud.net) + OpenStreetMap Nominatim
- **Данные:** IP-адрес (автоматически) или координаты браузера (с вашего согласия)
- **Цель:** Определение названия города для виджета погоды
- **Важно:** Geolocation используется только если вы включили "Автоопределение местоположения" в настройках виджета погоды

#### RSS Widget (RSS-ленты):
- **API:** Прямое обращение к RSS-лентам, указанным вами
- **Данные:** URL RSS-ленты
- **Цель:** Получение списка публикаций
- **Proxy:** Запросы проходят через background service worker расширения для обхода CORS

#### Обои (Wallpaper):
- **API:** Unsplash Images (https://images.unsplash.com)
- **Данные:** Нет (встроенная галерея из 8 предзагруженных изображений)
- **Цель:** Отображение HD-обоев

**Важно:** Мы не контролируем политики конфиденциальности этих сторонних сервисов. Пожалуйста, ознакомьтесь с их документацией.

---

### 3. Разрешения браузера

DashFlow запрашивает следующие разрешения Chrome Extension API:

#### `storage` (обязательное):
- **Цель:** Сохранение настроек и пользовательских данных локально
- **Данные:** Все перечисленные выше локальные данные

#### `bookmarks` (опциональное):
- **Цель:** Импорт закладок браузера в Bookmarks Widget
- **Данные:** Список закладок браузера (только при явном импорте)
- **Важно:** Используется только если вы нажали кнопку "Импорт закладок"

#### `geolocation` (опциональное):
- **Цель:** Автоопределение города для виджета погоды
- **Данные:** Координаты устройства (браузер запросит отдельное согласие)
- **Важно:** Используется только если включен "Автоопределение местоположения"

#### `host_permissions` (для внешних API):
- `https://api.open-meteo.com/*` — прогноз погоды
- `https://geocoding-api.open-meteo.com/*` — поиск городов
- `https://api.bigdatacloud.net/*` — геокодирование
- `https://nominatim.openstreetmap.org/*` — геокодирование
- `https://images.unsplash.com/*` — обои
- `https://*/*`, `http://*/*` — для RSS Widget и Iframe Widget

## Как мы используем данные

### Локальные данные:
- **Персонализация:** Сохранение ваших настроек, виджетов и контента
- **Синхронизация:** Восстановление состояния при открытии новой вкладки
- **Миграции:** Безопасное обновление схемы данных при выходе новых версий

### Сетевые запросы:
- **Функциональность:** Обеспечение работы виджетов (погода, RSS, iframe)
- **Актуальность:** Получение свежих данных от внешних источников

**Мы НЕ используем данные для:**
- Отслеживания вашего поведения
- Показа рекламы
- Продажи третьим лицам
- Создания профилей пользователей
- Аналитики и метрик

---

## Как мы защищаем данные

1. **Локальное хранение:** Все данные остаются в браузере, на вашем устройстве
2. **Нет серверов:** У DashFlow нет backend-серверов для сбора данных
3. **Изоляция:** Iframe Widget изолирован через sandbox без доступа к основному контексту
4. **Content Security Policy:** Строгий CSP блокирует выполнение небезопасного кода
5. **Manifest V3:** Соответствие современным стандартам безопасности Chrome
6. **Open Source:** Исходный код доступен для аудита на GitHub

---

## Ваши права

Вы имеете право:

1. **Доступ:** Просмотреть все данные через DevTools → Application → Storage → Extension
2. **Экспорт:** Экспортировать настройки через Settings → Data Management → Export
3. **Удаление:** Удалить все данные через Settings → Data Management → Clear All Data
4. **Отзыв разрешений:** Отключить разрешения через chrome://extensions
5. **Удаление расширения:** Полное удаление DashFlow удалит все локальные данные

---

## Хранение и удаление данных

### Срок хранения:
- Данные хранятся **бессрочно** до тех пор, пока вы не удалите их вручную или не удалите расширение

### Удаление данных:
1. **Полное удаление:** Settings → Data Management → Clear All Data
2. **Частичное удаление:** Удалите конкретный виджет или контент
3. **Удаление расширения:** Удалите DashFlow из chrome://extensions
