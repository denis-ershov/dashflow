## 2. Описание сервиса

DashFlow — это **бесплатное расширение для браузера с открытым исходным кодом**, которое заменяет стандартную новую вкладку браузера на персонализированный продуктивный дашборд с виджетами.

### Ключевые характеристики:
- Локальное хранение всех данных (без облачных серверов)
- 12 встроенных виджетов (часы, погода, задачи, заметки, RSS и др.)
- Настраиваемые темы, обои и звуки окружения
- Открытый исходный код (GPL-3.0 License)

## 5. Конфиденциальность и данные

### Локальное хранение:
- Все пользовательские данные (настройки, виджеты, контент) хранятся **локально** в вашем браузере
- Мы **не имеем доступа** к вашим данным
- Мы **не собираем телеметрию, аналитику или метрики использования**
- Мы **не используем cookies** для отслеживания

### Внешние API:
Некоторые виджеты обращаются к публичным API для получения данных:
- **Погода:** Open-Meteo API
- **Геолокация:** BigDataCloud + OpenStreetMap (только при включённом автоопределении города)
- **RSS:** Прямые запросы к RSS-лентам, указанным вами
- **Обои:** Unsplash Images (предзагруженная галерея)

Подробности в [Политике конфиденциальности](PRIVACY.md).

## 6. Разрешения браузера

DashFlow запрашивает следующие разрешения:

| Разрешение | Цель | Когда используется |
|:---|:---|:---|
| `storage` | Сохранение настроек локально | Постоянно |
| `bookmarks` | Импорт закладок | Только при явном действии пользователя |
| `geolocation` | Автоопределение города | Только если включено в настройках |
| `host_permissions` | Запросы к API погоды, RSS, iframe | При использовании соответствующих виджетов |

**Вы можете отозвать любое разрешение** через `chrome://extensions` → DashFlow → Details → Permissions.
